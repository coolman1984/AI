# Vault Index — FOREMAN Second Brain

Welcome. This is the curated, human-readable memory for the FOREMAN system.
Open this folder in Obsidian for the best experience.

## How to read this vault in 5 minutes

1. Start here (this page) — understand the structure
2. Open `notes/` — contains business rules, dataset profiles, mappings
3. Open `glossary/` — definitions of terms that caused confusion
4. Open `lessons/` — lessons captured from completed runs
