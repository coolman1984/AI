# Cost Center

## Definition
A organizational unit within a company to which costs can be recorded and tracked separately. Cost centers are used for internal cost allocation and reporting.

## SAP Field
`KOSTL` — alphanumeric code (e.g., "CC-PROD-001")

## Synonyms
- Cost object
- Cost code
- Department code (informal)
